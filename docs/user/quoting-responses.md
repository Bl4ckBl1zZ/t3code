# Quoting an assistant response

On web and desktop, select text in an assistant response and choose Cite. The
composer adds a quote chip and opens an optional comment field. Enter saves the
comment; Shift+Enter adds a line; Command/Ctrl+Enter saves and sends it. The pencil
edits a saved comment, and the chip's remove button removes the quote. Quotes and
comments stay with drafts, stashed prompts, and copied messages.

On iOS, open an assistant response's context menu and choose Cite text. Select the
passage, tap Cite, add an optional comment, and Save. Quote chips appear above the
composer. You can edit or remove each one without changing the rest of your draft.
Dictation edits the draft's prose while preserving its quotes.

Select a sent quote or a draft chip to return to its source. On iOS the quote opens
in a preview first; choose View source response to navigate. The app loads earlier
turns when necessary. If the source is unavailable, the saved quote and comment
remain readable. Web reveals folded source responses and marks the quoted text.

Quotes and comments can each contain up to 8,000 characters. The provider receives
the selected text as quoted material, with your comment identified separately as
your request. Citation links work across connected environments and contain no
server address. Creating quotes requires a server that supports assistant citations.
