# Browser profiles

In desktop Settings → Integrations → Browser profiles, add a profile to keep a separate set of
cookies and logins. Rename it or choose it as the default for new tabs. In a browser tab’s More
menu, choose **New tab in profile** to open a different profile or Incognito. Existing tabs keep
their profile. Incognito data lasts until you quit the desktop app.

Choose **Add profile → Import from** to copy cookies from another installed browser. The wizard
lets you select the source browser profile and an existing or new destination. The destination
is scoped to the environment shown in the wizard. Quit the source browser if prompted. On
macOS, allow the Keychain prompt; Safari may require Privacy & Security → Full Disk Access.
The wizard reports imported and skipped cookies. Some sites require signing in again.

Removing a profile deletes its cookies and cache across your known environments. The
built-in default profile can be cleared but cannot be removed. Browser profiles are local to
this desktop installation and do not synchronize passwords or cookies to other devices.
