# Set up your computers and agents

Open **Settings → Set up T3 Code** to connect computers, review your agent accounts, and
bring existing Claude Code or Codex conversations into T3 Code. New installations offer
setup automatically. You can skip setup or return to it later.

Choose the computers you want to use. Each computer keeps its own agent accounts and local
files. In the Agents step, configure an account or open its install or sign-in terminal.
Review the suggested command and press Enter when you are ready to run it. Closing the
terminal ends that setup session.

The Projects step looks for recent conversations in your configured Claude Code and Codex
accounts. Repositories with at least three conversations active in the last 30 days are
selected initially; other folders can be expanded and selected manually. Copies of the same
repository are grouped together, so you can choose the checkout you want. A scan-limit notice
means some history may not appear.

Importing adds the selected projects and their visible conversation history. Imported
conversations appear in **Settled** and can be resumed. Retrying an import does not duplicate
completed conversations or replace history you have already continued in T3 Code. If some
history cannot be imported, retry or continue without it.

Setup is available on web, desktop and the native iOS app. Older connected servers may need
an update before they support history import or account-specific setup terminals.
