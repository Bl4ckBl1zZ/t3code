⏳ Row states

Clock = waiting · Spinner + tinted border = dispatching (controls lock) · Red border = last dispatch failed, error shown inline, waits for edit/delete.

✏️ Inline edit

Pencil swaps the row into a textarea (desktop: ⌘↵ save, esc cancel; mobile: check/✕ buttons). While editing, the drain holds that message so a stale payload can never send.

↕ Reordering

Chevrons swap a row with its neighbor. First row's "up" and last row's "down" are disabled. On mobile the order persists across restarts (timestamp swap in the outbox).

⬆ Queue affordance

While the agent runs, the send button becomes "Queue" — next to Stop on desktop, tagged on the send button on mobile. Queue caps at 10 per thread.
